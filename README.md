# Words Guessing Game – Backend API

This repository contains the backend API for the **Words Guessing Game**, built using **FastAPI**, a modern Python web framework.

The backend manages game logic, match lifecycle, player timing, word validation, scoring, and leaderboard generation.

---

## Features

- Start and manage word-guessing matches
- Random letter generation per match
- Player join limits (max 2 players per match)
- Per-player time limits (45 seconds)
- Server-side word validation
- Prevention of duplicate word submissions
- Match-based scoring system
- Leaderboard generation
